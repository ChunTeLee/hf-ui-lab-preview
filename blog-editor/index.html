Blog Editor — design explorations

Interactive demos built with real moon-landing components, icons and type. Nothing here talks to a backend.

Option 1 · Franck-based

Editor + article settings panel

The URL moves to the top; thumbnail and authors live in a persistent, collapsible right panel with a big 1.91:1 preview. Footer keeps last-saved status, delete, draft and publish.
Option 2 · Simplify

One quiet canvas

No Edit/Preview tabs — preview is a toggle on the editor itself. The syntax guide collapses to chips and all metadata tucks behind an “Article settings” popover in the footer.

Try: the Preview toggle, the Publish modal, Option 1’s panel-collapse handle, Option 2’s Article settings, removing/re-adding the thumbnail.

Sources: layouts from Chunte’s Figma sketches; components, icons, logo and type ported from the latest moon-landing (CommunityBlogEditorForm, BlogPublishModal, components.css, ThemeSwitcher).
